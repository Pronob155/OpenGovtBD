# OpenGovtBD

A modern **Government Citizen Engagement Platform** built with **Java 17**, **Spring Boot**, and **Thymeleaf**. OpenGovtBD aims to bridge the gap between citizens and government services by providing a centralized platform for complaints, discussions, suggestions, polls, and public service access.

---

## ✨ Features

- 🔐 Role-Based Authentication
- 📝 Complaint Management & Tracking
- 💬 Public Discussion Forum
- 📊 Official Polls & Voting
- 💡 Suggestion Box
- 🔔 Notification Center
- 📈 Admin Dashboard & Analytics
- 🌗 Light & Dark Mode
- 📱 Fully Responsive Design

---

## 🚀 Getting Started

### Prerequisites

- Java 17+
- Maven 3.8+

### Run the Project

```bash
git clone https://github.com/pbs002-s/OpenGovtBD.git
cd OpenGovtBD
mvn spring-boot:run
```

Visit:

```
http://localhost:8080
```
