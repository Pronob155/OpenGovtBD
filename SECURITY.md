## 📋 Supported Versions

| Version | Status | Support Level |
| :--- | :---: | :--- |
| `v1.0.x` | 🟢 Current | Full support |
| `v0.9.x` | 🟡 Beta | Critical fixes only |
| `v0.5.x` | 🔴 Alpha | Not supported |
| `< v0.5.0` | ⚫ Legacy | Not supported |

> ⚠️ Only the latest version receives full security updates. Upgrade recommended for older versions.

---

## 🚨 Reporting a Vulnerability

We appreciate your help in keeping OpenGovtBD secure. Please follow responsible disclosure practices.

### 📬 Reporting Channel

| Channel | Action |
| :--- | :--- |
| 🔒 **GitHub Security Advisory** | [Submit a Private Report](https://github.com/opengovtbd/opengovtbd/security/advisories/new) |

> ❌ **Do NOT** report vulnerabilities through public issues, pull requests, or social media platforms.

---

### 📝 What to Include

| Information | Importance |
| :--- | :---: |
| Description of the vulnerability | 🔴 Required |
| Steps to reproduce | 🔴 Required |
| Affected version(s) | 🔴 Required |
| Potential impact | 🟡 Recommended |
| Proof of concept / Screenshots | 🟡 Recommended |
| Suggested fix | 🟢 Optional |

---

### ⏱️ Response Timeline

| Stage | Timeframe | Details |
| :--- | :---: | :--- |
| 📨 Initial Response | **48 hours** | Acknowledgment of your report |
| 🔍 Assessment | **3-5 business days** | Verification and severity analysis |
| 🛠️ Fix Development | Varies by severity | Development and testing |
| 🚀 Patch Release | As soon as ready | Public release of the fix |

---

### ✅ What to Expect

| Scenario | Outcome |
| :--- | :--- |
| **Accepted** | Fix prioritized, regular progress updates |
| **Declined** | Detailed explanation of reasoning |
| **Duplicate** | Notification that issue is already known |
| **Need More Info** | We will contact you for additional details |

## 🔐 Security Best Practices

All authorized contributors are required to follow these practices:

| # | Practice | Requirement |
| :---: | :--- | :---: |
| 1 | 🔑 **SSH Keys** | Use SSH keys for repository access |
| 2 | 🔒 **Two-Factor Authentication** | Enable 2FA on GitHub account |
| 3 | 🤫 **No Secrets** | Never commit API keys, passwords, or tokens |
| 4 | 🔄 **Dependencies** | Keep all dependencies updated regularly |
| 5 | 👀 **Code Review** | All changes must pass peer review before merge |
